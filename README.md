# 畢業之後 我的夢想之旅

高中職畢業生的升學 RPG。從高三開學一路走到畢業典禮，玩家和同學、學長姐一起探索畢業後的升學道路，最後帶走一張「我的畢業冒險攻略」。

> 未來不是選出來的答案，而是走出來的路。

純 HTML／CSS／JavaScript，不需要後端、登入或 API Key，可直接用 GitHub Pages 部署。遊戲進度存在瀏覽器的 localStorage。

## 檔案結構

```
index.html           遊戲入口
data-check.html      招生資料檢查頁（每年更新資料後打開）
data/
  admissions.js      ★ 招生管道、資格規則、日期、身分題目（每年要更新的檔案）
  departments.js     未來城市：8 個學習世界與正修科系、科系連結（CSU_DEPT_LINK）
  qrcodes.js         各網址的 QR Code（自動產生，不用手改）
tools/
  make_qr.py         新增網址時，重新產生 qrcodes.js
js/
  story.js           劇情文案：NPC 台詞、情報碎片、裝備、結局
  game.js            遊戲引擎（不含任何招生資訊，平常不用改）
css/style.css        樣式
assets/future-city.jpg  未來城市插圖
```

## 部署到 GitHub Pages

1. 把整個資料夾的內容上傳到 repository 根目錄（例如 `pursue-dreams1`）。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後即可開啟 `https://<帳號>.github.io/<repository>/`。

## 每年更新招生資訊（只改 data/admissions.js）

1. **學年度**：改 `meta.cycle`（例如 `"117學年度"`）、`meta.updated`，以及劇情時間軸 `meta.schoolYear`（高三開學日 `start`、預估畢業典禮日 `graduation`）。
2. **日期**：改每條道路 `events` 裡的 `from`／`to`（格式 `YYYY-MM-DD`）。
   - 已對照正式簡章的單一日期，加上 `confirmed: true`。
   - 整條道路都確認完，把 `status` 改成 `"confirmed"`。全部確認後，遊戲裡的「推估」提醒會自動消失。
   - 每條道路請保留一個 `key: true`，代表最重要的時間點（學長提到「最早的報名」時會用）。
3. **資格有變**：改該道路的 `rules`（判斷規則）以及 `who`／`conditions`（給學生看的文字）。條件寫法在檔案最下方有說明。
4. **其他設定**：道路加上 `portfolio: true` 會提醒參加正修學習歷程說明會（說明會網址在 `contact.briefing.url`）；加上 `later: "work"` 表示玩家沒有選「邊工作邊讀書」時排在推薦最後（目前是進修部）。
   **每個時間點要做什麼**：`tips` 依事件名稱比對出小提示，通常不用改。
5. **文字內容**：`prep`（要準備什麼）、`pitfalls`（可能遇到的問題）、`csu`（正修相關資訊）、`url`（查看完整資訊連結）直接改字即可。
6. 用瀏覽器打開 `data-check.html`：
   - 紅字一定要修（通常是少了逗號、引號或日期格式錯）。
   - 黃字是提醒（例如日期還是推估、日期已全部過期）。
   - 「資格模擬」表格可以檢查規則改完後，各種身分的燈號是否正確。
7. 上傳 GitHub。

**QR Code**：攻略卡（含下載的圖片）與圖鑑會顯示 QR Code。網址固定不變時不用處理；如果新增或更換了網址，`data-check.html` 會提醒，執行 `pip install segno` 後再執行 `python tools/make_qr.py` 即可重新產生。

科系或世界有變動時改 `data/departments.js`；各系 `url` 填系網址後，「了解這個系」會直接連過去；留空時連到 `CSU_DEPT_FALLBACK`（正修官網學術單位頁）。「科系探索」按鈕連到 `CSU_DEPT_LINK`（目前是 https://recruit.csu.edu.tw/1111/ ）；想調整台詞、結局文字時改 `js/story.js`。

> 小提醒：在自己電腦直接雙擊 `index.html` 也能玩；資料檔是 `.js` 格式，不需要架伺服器。

## 遊戲流程

劇情跟著高三的真實時間走，所以「學測報名在畢業前就開始」這類時間關係都是對的；遊戲中的倒數以劇情當天計算，攻略卡上的「下一步」以真實的今天計算。

高三這一年分成 **7 關＋終章**。畫面上方的任務列一直顯示「第幾關／本關任務」，點它會打開「旅程地圖」，看每一關的任務與為什麼重要。關卡名稱、任務、說明都寫在 `js/story.js` 的 `stages`，改字不用動程式。

| 關卡 | 任務（玩家要完成的事） | 內容 |
|---|---|---|
| 第 1 關 🪪 我是誰（9月） | 確認學制與身分 | 名字、學制問題（`admissions.js` 的 `stage: "create"`）、現在的心態 → 能力值 |
| 第 2 關 💬 聽聽大家怎麼想（9月） | 看看同學的打算 | 三年八班班群，選一位同學聊天 |
| 第 3 關 🛣️ 發現升學道路（10月） | 知道去同一個系不只一條路 | 學長登場、三條岔路（目標／未來城市／學長姐故事） |
| 第 4 關 🎒 背包檢查（10月底） | 盤點成績、證照、特殊經歷 | 背包問題（`stage: "backpack"`），道路依身分亮燈 |
| 第 5 關 ⏰ 看清楚時間（11月） | 找出道路什麼時候報名 | 「之後再說」或「先看時間」→ 真實報名倒數 |
| 第 6 關 💪 我願意準備（11月） | 選出還願意多準備的事 | 重新檢視、可複選的準備項目（即時顯示對應的道路）、推薦道路 |
| 第 7 關 📝 寫下升學策略（11月底） | 選出主攻、備選、備援 | 三格策略＋出發前帶的裝備 |
| 終章 🎓 畢業典禮（6月） | 帶走攻略卡 | 時光快轉（可略過）→ 5 種結局 → 我的畢業冒險攻略 |

每一關結束時，黑板會寫下「這一關你拿到了什麼」與下一關的任務，按一下就由板擦擦掉、用粉筆寫出新的倒數天數。點一下黑板可以讓粉筆字一次寫完。系統設定「減少動態效果」時，動畫會自動省略。

### 真實日期與「已截止」提醒
- 遊戲以**真實的今天**計算所有倒數與報名狀態：手機日期會先和網路時間（GitHub Pages 回應的時間）核對，相差超過 12 小時就改用網路時間。
- 劇情日期如果早於今天，就直接用今天；過場黑板會標「今天」或「劇情快轉到」。
- 每條路的「入口」是 `events` 的第一項；想指定別的時間點，在那一項加上 `gate: true`。入口過了就標 ⛔ 今年已截止，不列入推薦和升學策略。
- 30 天內開始或正在報名的路會標 🔥／⏳；回到標題畫面和攻略卡都會提醒；策略裡有路已截止時，攻略卡出現「重新寫升學策略」。
- 測試：網址加上 `?today=2027-03-15` 可以模擬任何一天。

### 上一步與暫存
- **↩ 上一步**：回到前一個選擇重新選，能力值、碎片、解鎖的道路也會一起還原。純展示的畫面（例如亮燈結果）會自動跳過。
- **💾 暫存**：每走一步都會自動存在瀏覽器（localStorage，鍵值 `grad-journey-v4`）。暫存視窗可以「立即暫存」、「複製續玩連結」（換手機、換電腦打開連結就能接著玩，「上一步」的紀錄也會一起帶走），或貼上續玩連結載入。
- 在 LINE、IG 等 App 內建瀏覽器開啟時，關掉視窗可能清掉暫存，建議玩家先複製續玩連結。
- 舊版（v3）存檔不會被讀取，玩家會從頭開始。

### 裝備的功能
| 裝備 | 點了之後 |
|---|---|
| 🧭 升學地圖 | 打開升學路線圖鑑 |
| 🔍 科系探索鏡 | 打開未來城市 |
| 📜 資格卷軸 | 列出你每條路的資格燈號與原因 |
| ⏰ 時間警報器 | 你的道路一年時間軸，並可「加入手機行事曆」（提前 3 天提醒） |
| 🧭 學長姐的手繪地圖 | 學長姐的升學故事，可直接看那條路 |
| 🔍 正修探索鏡 | 連到正修科系介紹（`CSU_DEPT_LINK`） |
| 🎒 參訪通行證 | 連到 `contact.visit`（目前是 https://recruit.csu.edu.tw/1111/ ） |
| 🎒 求助對講機 | 正修官方 LINE@（一對一專人回答）、招生處專線電話與 QR Code |
